# Shruti Dhamde Resume

A standalone, locally editable resume builder. Open `index.html` in a browser; no server or external JavaScript packages are required for editing.

## Editing and saving

- Click resume text to edit it. Changes are saved in that browser when local storage is available.
- Use **Save editable backup** to download a JSON copy. Use **Load backup** to restore it later or in another browser.
- **Download ATS text** produces a plain text version in reading order and excludes the photo.
- **ATS check** flags obvious missing contact details, hidden core sections, and template placeholders. It is a basic readability check, not an ATS score.

The default phone number is masked. Replace it before applying. Submit a format accepted by the employer; the plain text export is intended for inspection and for applications that accept `.txt` files.

Drag reordering is disabled in this offline version. Text editing and adding or removing entries remain available.
